# IA em Cena

Crie um site responsivo com design de interface urbana no estilo grafite, garantindo legibilidade nas fontes e elementos visuais. A estrutura deve conter uma página inicial dinâmica com seções bem definidas e cartões informativos para cada IA listada. Cada card deve exibir o nome da ferramenta, uma descrição clara de sua função e aplicabilidade prática, uma avaliação objetiva de seus pontos fortes, e a indicação de se o modelo
